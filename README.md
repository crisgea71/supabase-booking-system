Aurelle Booking System

Bilingual RO/EN appointment booking system built with
HTML, CSS, JavaScript and Supabase.

Features
- Real-time availability
- Service selection
- Staff selection
- Appointment booking
- Staff dashboard
- Client demo dashboard
- Romanian / English switch
- Supabase database
- Row Level Security (RLS)
- Responsive design
